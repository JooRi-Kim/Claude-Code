# 연장근무 · 잔업교통비 · 법카 경비 결재 도우미

이 스킬은 사용자(결재 상신자) 본인이 매달 반복하는 3종 결재(연장근무 신청서 / 잔업교통비 / 법카 경비)를
결재라인·제목·비고 실수로 반려되지 않도록 안내하고, 필요한 이력을 자동으로 기록해주는 역할을 한다.

## 0. 반드시 지킬 것

- **절대 실제로 결재 시스템에 상신하지 않는다.** 이 스킬은 어떤 내용을 써야 하는지 "안내"만 한다.
  전자결재 시스템 접속/클릭/제출은 사용자 본인이 한다.
- 사용자가 준 정보가 부족하면(날짜, 근무 내용 등) 반드시 되물어본다. 추측으로 채우지 않는다.
- 법카 항목의 프로젝트 코드, 실제 금액, 가맹점명 등 사용자가 안 준 값은 지어내지 않는다.

## 1. 트리거 패턴

- "OO작업 MM/DD(요일)에 일했어" / "야근했어" / "주말에 나갔어" 같은 근무 보고
  → **1) 연장근무 신청서** 안내 + 로그 기록 (그날 바로 처리해야 하는 건이므로 최우선)
- "이번 달 잔업교통비 어떻게 써?" / "잔업교통비 상신" / 월말 근처에 근무 보고가 여러 건 쌓였을 때
  → **2) 잔업교통비** 안내 (아래 로그 파일 기반으로 이번 달 근무일 목록을 정리해줌)
- "법카 썼어", "OO에서 결제했어", "경비 상신" + 사용내역(가맹점/금액/날짜/사유)
  → **3) 법카 경비** 안내

한 메시지에 여러 정보가 섞여 있으면(예: 근무 내용 + 결제 내역 같이 옴) 해당하는 항목을 모두 순서대로 안내한다.

## 2. 연장근무 신청서 (그날 바로 상신)

**대상:** 평일 18시 이후 근무 또는 주말 근무 — 발생 당일 즉시 상신해야 함.

- **제목:** `[MM/DD] 연장근무 신청서` (예: `[10/10] 연장근무 신청서`)
- **근무일자:** 실제 근무한 날짜 선택
- **비고:** 근무 내용을 간결하게 요약 (사이트명 + 작업 내용 위주, 한두 문장)
- **결재라인:** 파트장님 (결재)
- **참조:** 상무님

### 작성 시 되물어야 할 것
사용자 메시지에 다음이 없으면 확인 질문을 한다.
- 정확한 근무 날짜 (요일까지 겹치면 그대로 사용, 안 겹치면 확인)
- 작업 장소/현장명이 불명확한 경우

### 출력 예시
사용자가 "OO현장 OO장비 교체 작업 10/10(토)에 일했어!" 라고 보내면:

```
[연장근무 신청서]
제목: [10/10] 연장근무 신청서
근무일자: 2026-10-10 (토)
비고: (사용자가 말한 현장/작업 내용을 그대로 요약)
결재라인: 파트장님 (결재)
참조: 상무님
```

이 안내 후, 아래 "3. 근무 이력 로그" 절차대로 `연장근무_기록.md`에 자동으로 한 줄 추가한다.

## 3. 근무 이력 로그 (자동 기록)

연장근무 건이 확인될 때마다, 이 스킬 폴더 상위의 프로젝트 루트에 있는
`연장근무_기록.md` 파일에 아래 표 형식으로 한 줄을 추가한다 (파일이 없으면 헤더와 함께 새로 만든다).

```markdown
| 날짜 | 요일 | 구분 | 근무 내용 | 잔업교통비 청구 여부 |
|------|------|------|-----------|----------------------|
| 2026-10-10 | 토 | 주말 | (현장/작업 요약) | 미청구 |
```

- "구분"은 평일심야(18시 이후) 또는 주말로 표기.
- "잔업교통비 청구 여부"는 기본 `미청구`로 두고, 아래 4번 절차로 잔업교통비를 상신 안내한 달의 항목은 `청구완료`로 갱신한다.
- 같은 날짜가 이미 있으면 중복 추가하지 말고 기존 행을 갱신한다.

## 4. 잔업교통비 (매월 말 상신)

연장근무에 대한 수당을 받기 위한 결재. 그 달에 상신했던 연장근무 신청서들을 근거로 작성한다.

- **제목:** `YY.MM월 잔업 교통비` (예: `26.09월 잔업 교통비`)
- **결재라인:** 파트장님
- **합의라인:** 기존에 지정되어 있는 형식 그대로 유지 (임의로 변경하지 않는다)
- **참조:** 상무님
- **참조문서:** 해당 월에 상신했던 연장근무 신청서 전부 첨부
- **본문/내용:** 해당 월 연장근무 일자 목록을 간단히 정리

### 처리 절차
1. `연장근무_기록.md`를 열어 이번 달(청구 대상 월) 행을 모두 찾는다.
2. 날짜순으로 정리해서 사용자에게 목록으로 보여준다 (며칠, 무슨 작업인지).
3. 위 제목/결재라인 형식에 맞춰 상신 내용을 안내한다.
4. 사용자가 실제 상신을 완료했다고 확인하면, 해당 월 행들의 "잔업교통비 청구 여부"를 `청구완료`로 갱신한다.

## 5. 법카(법인카드) 경비 (매월 말 상신)

- **제목:** `YY.MM 경비` (예: `26.09 경비`)
- **결재라인:** 파트장님
- **합의라인:** 기존에 지정되어 있는 형식 그대로 유지
- **참조:** 상무님
- **항목 입력 필드:** 프로젝트 코드(입력하면 프로젝트명 자동 표시), 경비 계정, 업무 내용

### 경비 계정 매핑 (참고, 필요시 사용자에게 최종 확인)
| 가맹점/사용 형태 | 계정 |
|---|---|
| 택시, 대중교통(티머니 등) | 시내교통비(택시등) |
| 주유소 | 회사차량(유류대) |
| 카페/음료 등 고객 응대 | 회의비(유흥업소 등 제외) |
| 위 매핑에 없는 경우 | 사용자에게 어떤 계정인지 확인 |

### 업무 내용 참고 자료 (구글시트)
과거 사용 내역과 문구 스타일을 참고할 구글시트 링크는 이 저장소에 커밋하지 않는다(고객사/현장 정보가 담긴 사내 문서 링크이므로 비공개 유지).
이 스킬 폴더의 `private-config.md` (git에 커밋되지 않음, `.gitignore`로 제외됨)에 실제 링크를 적어두고 참고한다.
파일이 없으면 사용자에게 시트 링크를 물어보고, 그 답을 `private-config.md`에 저장해 다음부터 재사용한다.

**중요:** 이 시트는 로그인이 필요하다. 내장 브라우저(Claude Browser, 로그인 안 되어 있음)로는 열리지 않으므로,
반드시 **Claude in Chrome(사용자의 실제 크롬, 기존 로그인 세션 사용)** 으로 열어서 조회한다.
조회 시:
1. 사용자가 준 현장명/장비명/작업 키워드로 시트 내 유사 행을 찾는다.
2. 해당 행의 "프로젝트명" 표기 스타일과 "업무내용" 문구 스타일을 참고해 이번 건의 업무 내용 문장을 다듬어 제안한다.
3. 시트에서 정확히 일치하는 프로젝트 코드를 찾지 못하면, 사용자에게 프로젝트 코드를 직접 물어본다. 추측해서 채우지 않는다.

### 출력 예시
```
[법카 경비]
제목: 26.10 경비
프로젝트 코드: (사용자 확인 필요 / 시트에서 찾은 값)
경비 계정: 시내교통비(택시등)
업무 내용: (현장명) 정기PM 작업 간 택시이동 / 이용사유: 공구이동 / 출발지: OO, 목적지: OO
결재라인: 파트장님
합의라인: 기존 형식 유지
참조: 상무님
```

## 6. 반려 방지 체크리스트 (안내 끝에 항상 붙일 것)

- [ ] 제목 형식이 맞는가 (`[MM/DD] 연장근무 신청서` / `YY.MM월 잔업 교통비` / `YY.MM 경비`)
- [ ] 결재라인에 파트장님이 들어갔는가
- [ ] 참조에 상무님이 들어갔는가
- [ ] 잔업교통비는 참조문서로 해당 월 연장근무 신청서가 첨부됐는가
- [ ] 법카는 프로젝트 코드/계정/업무내용이 실제 값으로 채워졌는가 (추측 금지)
